# Cakoo — Bakery Website

A full-stack website for Cakoo, a bakery in Wah Cantt: a cinematic marketing site, online ordering, and an admin dashboard for managing products, orders, reviews, gallery, offers, and site content.

**Stack:** Next.js (App Router) · TypeScript · Tailwind CSS · PostgreSQL · Prisma · Framer Motion · Zustand

## Getting Started

1. **Install dependencies**

   ```bash
   npm install
   ```

2. **Configure environment variables** — copy `.env.example` to `.env` and fill in real values:

   ```bash
   cp .env.example .env
   ```

   - `DATABASE_URL` — PostgreSQL connection string.
   - `JWT_SECRET` — long random string used to sign admin session cookies.
   - `ADMIN_SEED_EMAIL` / `ADMIN_SEED_PASSWORD` — credentials for the admin account created by the seed script. **Change the password after first login.**
   - `NEXT_PUBLIC_SITE_URL` — public URL of the deployed site (used for metadata/sitemap).

3. **Set up the database**

   ```bash
   npx prisma migrate deploy   # apply migrations
   npm run seed                # create admin account, categories, starter products, gallery, settings
   ```

4. **Run the dev server**

   ```bash
   npm run dev
   ```

   Visit `http://localhost:3000` for the site and `http://localhost:3000/admin/login` for the admin dashboard.

## Project Structure

- `src/app/(site)` — public-facing pages (home, menu, gallery, checkout, custom cakes, legal pages).
- `src/app/admin` — admin dashboard (`/admin/login` is public; everything else under `/admin` requires a session, enforced in `src/proxy.ts`).
- `src/app/api` — REST API routes. `src/app/api/admin/*` requires an authenticated admin session.
- `src/components` — UI components, grouped by area (`home`, `menu`, `gallery`, `checkout`, `admin`, `shared`, `layout`, `cart`).
- `src/lib` — server utilities: Prisma client, auth/session handling, validation schemas (Zod), data fetchers, image storage.
- `prisma/schema.prisma` — database schema. `prisma/seed.ts` — starter content.

## Replacing Placeholder Content

This build ships with **generated placeholder art** (no external images or video were available while building), plus a starter product catalog and gallery so the site isn't empty on first run:

- **Hero video**: the homepage looks for `/public/videos/cakoo-hero.mp4` with `/public/images/cakoo-hero-poster.svg` as the poster/fallback. Drop a real cinematic bakery video at that path (the component gracefully falls back to the poster image if the video is missing) — see `src/components/home/Hero.tsx`.
- **Product, gallery, and about photos**: currently SVG illustrations generated by `scripts/generate-placeholders.mjs`. Replace them with real photography via the admin dashboard's image uploader (Products, Gallery, Offers), or by re-running/editing that script.
- **Social links**: Facebook/Instagram/TikTok URLs are left blank by default (no real links were provided). Add them in **Admin → Site Settings**.
- **Reviews & offers**: seeded empty on purpose — real customer reviews and offers should be added via the admin dashboard rather than fabricated.
- **Opening hours, address, phone, email, hero/about copy**: all editable in **Admin → Site Settings**; defaults are pre-filled with the bakery's known address/phone from its Google Business listing.

## Image Uploads

Admin-uploaded images are stored on local disk under `/public/uploads` by default (see `src/lib/storage.ts`). To use cloud storage instead, set `STORAGE_PROVIDER=s3` plus the `S3_*` variables in `.env` and implement `uploadToS3()` in that file — the call sites elsewhere in the app don't need to change.

## Payments

Checkout currently supports **Cash on Pickup/Delivery** and **Card on Delivery**. An "Pay Online" option is present in the schema and UI but disabled ("Coming soon") since no payment provider credentials were available — wire up a provider (e.g. Stripe) and enable that option in `src/components/checkout/CheckoutForm.tsx` when ready.

## Scripts

- `npm run dev` / `npm run build` / `npm run start` — standard Next.js scripts.
- `npm run lint` — ESLint.
- `npm run seed` — (re)run the database seed script.
- `npm run generate-placeholders` — regenerate the local placeholder SVG art.

## Admin Dashboard

Manage products & categories, orders (with status tracking), reviews (approve before they go public), gallery images, promotional offers, contact messages, custom cake requests, and site-wide content (hero text, about text, contact info, hours, social links) — all from `/admin`.

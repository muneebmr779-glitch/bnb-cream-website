# Shape Shifters Gym — Website

A fast, responsive, single-page website for **Shape Shifters Gym, Wah Cantt** — *Forge Your Body. Engineer Your Life.*

## Features
- Black & orange brand design with animated hero, marquee and scroll reveals
- Services: Personal Training, Cycling, Zumba, Aerobics
- Our Story timeline and Branch 3 grand-opening announcement bar
- Branch cards (Sardar Plaza, Lalarukh Basti, New City Phase 2) with call & directions links, plus an embedded map
- Enquiry form that composes a WhatsApp message to the gym
- Mobile menu, floating call button, reduced-motion support

## Run locally
No build step. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Files
- `index.html` — page markup and content
- `styles.css` — all styling
- `script.js` — menu, scroll effects and the WhatsApp enquiry form
